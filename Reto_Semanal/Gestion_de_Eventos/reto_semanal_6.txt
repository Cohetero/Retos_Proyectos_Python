Reto Semanal #6 (Avanzado) – Sistema de Gestión de Eventos con Base de Datos

🎯 Objetivo:
Crear una aplicación en consola que permita registrar, listar, editar, eliminar y buscar distintos eventos culturales (conciertos, exposiciones, talleres), utilizando una base de datos SQLite para la persistencia.

📁 Estructura mínima del proyecto:
reto6_eventos/
├── main.py
├── eventos/
│   ├── evento.py          # Clase abstracta
│   ├── concierto.py       # Clase hija
│   ├── exposicion.py
│   └── taller.py
├── db/
│   └── conexion.py        # Conexión y ejecución SQL
├── utils/
│   ├── validador.py
│   └── errores.py
└── README.md              # (opcional)

💾 Base de datos (SQLite):
- Tabla: eventos ✅
- Campos:
  - id INTEGER PRIMARY KEY AUTOINCREMENT
  - tipo TEXT (concierto, exposición, taller)
  - nombre TEXT
  - fecha TEXT
  - ubicacion TEXT
  - extra1 TEXT
  - extra2 TEXT
  - extra3 TEXT (solo si aplica, como en Taller)

🛠️ Funcionalidades CRUD:
1. Crear evento (con validación) ✅
2. Listar eventos (todos o filtrados) ✅
3. Buscar por fecha ✅
4. Editar evento por ID ✅
5. Eliminar evento por ID ✅

🧬 Clases:
Clase abstracta Evento:
- Atributos: nombre, fecha, ubicacion 
- Método abstracto: descripcion_detallada()

Subclases:
- Concierto: banda, genero
- Exposicion: artista, tipo_arte
- Taller: ponente, duracion_horas, requisitos

🔐 Validaciones y errores personalizados:
validador.py:
- validar_fecha() → no aceptar fechas pasadas✅
- validar_texto() → sin campos vacíos ✅

errores.py:
- FechaInvalidaError ✅
- CampoVacioError ✅

🌟 Extras (opcional):
- Ordenar eventos por fecha ✅
- Exportar resultados a CSV
- Confirmación antes de eliminar ✅
- Colores en consola (con colorama) ✅
- Interfaz mejorada (con rich)
